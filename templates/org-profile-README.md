## The doctrine

Source, running software, and model evaluations are **separate claims**. A green test is not a deployment; a deployment is not a proof. Unknowns stay visible. Supply-chain security is converging on this discipline — SLSA, in-toto, Sigstore — except here it isn't bolted on. It's the product.
